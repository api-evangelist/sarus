# Sarus

> Sarus Technologies (Paris, Y Combinator W22) builds a privacy layer between sensitive data and the analysts, data scientists and LLMs that use it. The Sarus platform is deployed inside the customer's own infrastructure and applies differential privacy, synthetic data and SQL/Python query rewriting. Developers reach it through the first-party `sarus` Python client for the Sarus Gateway, and through Qrlew, Sarus's open-source Rust SQL-rewriting and differential-privacy engine and its small REST server. There is no hosted multi-tenant API and no published OpenAPI; the Gateway host is a deployment variable.

This file was generated by API Evangelist from the public profile at https://github.com/api-evangelist/sarus — Sarus does not publish its own llms.txt (https://www.sarus.tech/llms.txt returns 404).

## APIs

- [Sarus Gateway API](https://pypi.org/project/sarus/): customer-deployed Gateway at `https://{sarus-gateway-host}/gateway`, reached with `from sarus import Client; Client(url=..., email=...)`. Session-cookie login (POST /login) or Google OIDC.
- [Qrlew Server API](https://github.com/Qrlew/server): self-hosted REST wrapper for the Qrlew engine (`docker run -p 3000:3000 ghcr.io/qrlew/server:main`) — GET /public_key, POST /dot, /rewrite_as_privacy_unit_preserving, /rewrite_with_differential_privacy, /verify.
